## Getting Started

### Logging In
1. Navigate to your PisoNet system URL
2. Enter your username and password
3. Click "Login"

**Default Admin Credentials:**
- Username: `admin@pisonet.com`
- Password: `password` (Change immediately after first login)

### First Time Setup
1. Change your password (Profile → Edit Profile)
2. Add your PC units (PC Units → Add New)
3. Configure machine settings
4. Review system settings

## Dashboard Overview

The dashboard provides a real-time overview of your PisoNet business:

### Key Metrics
- **Today's Earnings:** Total revenue for the current day
- **Transactions:** Number of completed transactions
- **Average Transaction:** Average revenue per transaction
- **Active Machines:** Number of machines currently online

### Charts
- **Weekly Earnings Chart:** Visual representation of earnings over the last 7 days
- **Earnings Breakdown:** Distribution by service type (Gaming, Browsing, Printing)

### Machine Status Grid
- **Green (Online):** Machine is available and ready
- **Blue (Busy):** Machine is currently in use
- **Red (Offline):** Machine is not responding

### Activity Feed
Real-time feed of recent activities including:
- Session starts
- Coin insertions
- Transaction completions

## PC Units Management

### Adding a New PC Unit
1. Navigate to **PC Units** from the sidebar
2. Click **"Add New PC Unit"** button
3. Fill in the details:
   - **PC Number:** Unique identifier (e.g., 1, 2, 3)
   - **PC Name:** Descriptive name (e.g., "Gaming Station 1")
   - **Location:** Physical location (optional)
4. Click **"Add PC Unit"**

### Editing PC Units
1. Find the PC unit in the list
2. Click the **Edit** icon (pencil)
3. Update the information
4. Click **"Update"**

### Activating/Deactivating PC Units
- Click the **toggle switch** next to the PC unit
- Green = Active, Gray = Inactive

### Deleting PC Units
1. Click the **Delete** icon (trash)
2. Confirm deletion
3. **Warning:** This will delete all associated session data

## Session Monitoring

### Viewing Active Sessions
1. Navigate to **Sessions** from the sidebar
2. View all active and past sessions

### Session Information
- **Session ID:** Unique identifier
- **PC Unit:** Which machine is being used
- **User Name:** Customer name (if provided)
- **Start Time:** When the session began
- **Remaining Time:** Minutes left in the session
- **Status:** Active or Ended

### Starting a New Session
1. Click **"Start New Session"**
2. Select PC Unit
3. Enter user name (optional)
4. Enter minutes purchased
5. Click **"Start Session"**

### Ending a Session
1. Find the active session
2. Click **"End Session"** button
3. Confirm action

### Extending a Session
1. Find the active session
2. Click **"Extend"** button
3. Enter additional minutes
4. Click **"Extend Session"**

## Earnings Tracking

### Viewing Earnings
1. Navigate to **Earnings** from the sidebar
2. Select filter: Daily, Weekly, or Monthly
3. View earnings summary and details

### Earnings Summary
- **Total Amount:** Sum of all earnings
- **Total Transactions:** Number of transactions
- **Completed:** Successfully completed transactions
- **Pending:** Transactions awaiting completion
- **Average Transaction:** Average earning per transaction

### Exporting Earnings
1. Select your desired filter (Daily/Weekly/Monthly)
2. Click **"Export PDF"** or **"Export Excel"**
3. File will download automatically

## Transactions

### Viewing Transactions
1. Navigate to **Transactions** from the sidebar
2. Filter by: Daily, Weekly, or Monthly
3. View transaction details

### Transaction Information
- **Transaction ID:** Unique identifier
- **PC Unit:** Machine used
- **Total Coins:** Amount paid
- **Total Minutes:** Time purchased
- **Start/End Time:** Session duration
- **Status:** Active, Completed, or Cancelled

### Transaction Charts
- **Earnings Trend:** Line chart showing earnings over time
- **Transaction Count:** Number of transactions per period
- **Status Distribution:** Breakdown by transaction status

### Exporting Transactions
- Click **"Export PDF"** or **"Export Excel"**
- Choose filter period
- Download report

## Coin Inserts

### Viewing Coin Inserts
1. Navigate to **Coin Inserts** from the sidebar
2. Select filter period
3. View all coin insertion records

### Coin Insert Information
- **Coin ID:** Unique identifier
- **PC Unit:** Machine where coin was inserted
- **Coin Value:** Amount inserted (₱)
- **Minutes Given:** Time credited
- **Inserted Time:** When coin was inserted

### Summary Statistics
- **Total Coin Value:** Sum of all coins inserted
- **Total Minutes:** Total time credited
- **Total Inserts:** Number of coin insertions
- **Averages:** Average coin value and minutes per insert

### Exporting Coin Inserts
- Click **"Export PDF"** or **"Export Excel"**
- Select filter period
- Download report

## Profile Management

### Viewing Your Profile
1. Click the **gear icon** (⚙️) in the sidebar footer
2. View your profile information

### Editing Your Profile
1. Click **"Edit Profile"** button
2. Update information:
   - Full Name
   - Username
   - Email Address
   - Phone Number
   - Address
   - Profile Picture
3. Click **"Update Profile"**

### Changing Password
1. Go to Edit Profile
2. Scroll to "Change Password" section
3. Enter new password
4. Confirm new password
5. Click **"Update Profile"**

**Note:** Leave password fields blank to keep current password

1. Click **"Choose File"** in Edit Profile
2. Select image (JPG, PNG, GIF)
3. Maximum size: 2MB
4. Preview will appear
5. Click **"Update Profile"** to save

## Troubleshooting

### Common Issues

#### Cannot Login
- **Solution:** Check username and password
- Ensure Caps Lock is off
- Contact administrator if forgotten

#### PC Unit Not Showing as Online
- **Solution:** Check machine connection
- Verify machine is sending heartbeat
- Check network connectivity

#### Session Not Starting
- **Solution:** Ensure PC unit is active
- Check if PC already has active session
- Verify minutes are greater than 0

#### Export Not Working
- **Solution:** Check browser pop-up blocker
- Ensure sufficient data exists
- Try different browser

#### Dashboard Not Updating
- **Solution:** Refresh the page (F5)
- Clear browser cache
- Check internet connection

### Error Messages

#### "Unauthorized Access"
- You don't have permission for this action
- Contact administrator

#### "Machine Not Found"
- Machine may have been deleted
- Check machine code is correct

#### "Session Already Active"
- PC unit already has an active session
- End current session first

## Glossary

- **PC Unit:** Individual computer station in your PisoNet
- **Session:** Period of time a customer uses a PC
- **Coin Insert:** Record of payment received
- **Transaction:** Complete record of a customer's usage
- **Earnings:** Revenue generated from services
- **Heartbeat:** Signal from machine indicating it's online
- **API Token:** Security key for machine communication
